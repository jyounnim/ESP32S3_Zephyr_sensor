# HLK-LD2402 24GHz mmWave 인체 존재 감지 센서 조사

> 기준 자료: Hi-Link 「HLK-LD2402 用户手册」 V1.08 (2025-03-18), 5장 통신 프로토콜.
> 보조 자료: ESPHome 커뮤니티 컴포넌트(hlk_ld2402_esphome, FW v3.5.5 기준).

## 1. 개요

HLK-LD2402는 Hi-Link의 **정지 인체 생명 존재 센서**입니다. 24GHz FMCW 1T1R 안테나와 MCU 펌웨어가 하나의 20×20mm 모듈에 들어 있으며, 운동·미동(breathing 수준)·정지 인체를 구분해 실시간으로 보고합니다. GPIO 출력과 UART를 모두 제공하므로, GPIO만 읽는 단순 ON/OFF 용도부터 UART로 거리·gate 에너지를 읽는 용도까지 사용할 수 있습니다.

## 2. 주요 사양

| 항목 | 값 | 비고 |
|---|---|---|
| 주파수 | 24.0 ~ 24.25 GHz | ISM band, sweep BW 250 MHz |
| 방식 | FMCW, 1T1R | |
| 전원 | 3.0~3.6 V (Typ 3.3 V) | LDO 실장품(“G” 버전)은 4.5~5.5 V. 기본품은 LDO 미실장 |
| 평균 전류 | 50 mA | 동작 중 발열 있음 |
| 데이터 갱신 주기 | 165 ms | |
| 감지 거리(벽 부착) | 운동 10 m / 미동 6 m / 정좌 5 m | 시야각 ±60° |
| 감지 거리(천장 부착) | 운동 5 m / 미동 4 m / 정좌 4 m / 정와 3 m | 높이 2.7~3 m 기준 |
| 거리 정밀도 | ±0.15 m | 6 m 이내 운동 목표 |
| Gate | 0.7 m × 16 gate (기본 유효 0~10 m) | |
| 동작 온도 | -40 ~ 85 °C | |

## 3. 핀 배치 (J2, 2.54/2.00 mm 겸용 피치)

| Pin | 이름 | 기능 | 레벨 |
|---|---|---|---|
| 1 | V | 전원 입력 | 3.3 V (LDO 실장 시 5 V) |
| 2 | IO | 감지 상태 출력: High = 사람 있음, Low = 없음 | 0~3.3 V |
| 3 | G | GND | |
| 4 | T | UART TX (센서 → MCU) | 0~3.3 V |
| 5 | R | UART RX (MCU → 센서) | 0~3.3 V |

J1은 SWD(DIO/CLK) 포트로, 모듈 MCU 펌웨어 업데이트용입니다.

**주의:** IO 레벨은 3.3 V 고정입니다. 1.8 V 도메인 MCU(예: SR110)와 직결하면 안 되며, 5 V 신호를 넣어도 안 됩니다.

## 4. UART 프로토콜

- 115200 bps, 8N1, **little-endian**입니다.
- 출력 포맷은 세 가지이며, 예제 드라이버는 셋을 자동 판별합니다.

### 4.1 Normal mode (공장 기본값)

ASCII 문자열을 줄 단위로 출력합니다.

```
OFF\r\n              ← 대상 없음
distance:123\r\n     ← 대상 있음, 거리 123 cm
```

이 모드에서는 운동/정지 구분과 gate 에너지를 알 수 없습니다.

### 4.2 Engineering mode (에너지 보고)

```
F4 F3 F2 F1 | len(2) | 검출결과(1) | 거리(2) | gate 에너지 32 × 4B | F8 F7 F6 F5
```

| 필드 | 크기 | 설명 |
|---|---|---|
| len | 2 | 0x0083 = 131 = 1 + 2 + 128 |
| 검출결과 | 1 | 0x00 무인, 0x01 유인, 0x02 유인 정지 |
| 거리 | 2 | cm |
| motion 에너지 | 16 × 4 | gate 0~15, raw 선형값 |
| micro/static 에너지 | 16 × 4 | gate 0~15, raw 선형값 |

dB 환산은 `dB = 10 × log10(raw)`입니다. 매뉴얼 예시인 gate0 = `F6 11 00 00` = 4598은 36.62 dB입니다. 예제 드라이버의 host 단위 테스트에서 이 예시 프레임을 그대로 넣어 거리 102 cm, gate0 37 dB로 디코딩되는 것을 확인했습니다.

### 4.3 Command / ACK

```
송신: FD FC FB FA | len(2) | cmd(2) value(N)              | 04 03 02 01
ACK : FD FC FB FA | len(2) | cmd|0x0100 (2) status(2) data | 04 03 02 01
```

status 0은 성공, 1은 실패입니다. **다른 모든 명령은 0x00FF(설정 활성화) 뒤에서만 유효**하며, 0x00FE(설정 종료) 후 다시 정상 보고를 시작합니다.

| cmd | 기능 | value | ACK data |
|---|---|---|---|
| 0x00FF | 설정 활성화 | `01 00` | 프로토콜 버전(2), 버퍼 크기(2) |
| 0x00FE | 설정 종료 | 없음 | 없음 |
| 0x0000 | 펌웨어 버전 읽기 | 없음 | 길이(2) + 문자열 (예: `v3.0.3`) |
| 0x0011 / 0x0016 | SN 읽기 (문자 / hex) | 없음 | 길이(2) + SN |
| 0x0008 | 파라미터 읽기 | ID(2) × N | 값(4) × N |
| 0x0007 | 파라미터 쓰기 | (ID(2) + 값(4)) × N | 없음 |
| 0x0012 | 출력 모드 설정 | `00 00` + 모드(4) | 없음 |
| 0x0009 | 자동 threshold 생성 시작 | trigger/hold/micro 계수(각 2B, ×10) | 없음 |
| 0x000A | 자동 threshold 진행률 | 없음 | 백분율(2) |
| 0x00FD | 파라미터 flash 저장 (FW ≥ 3.3.2) | 없음 | 없음 |
| 0x00EE | 자동 gain 조정 (FW ≥ 3.3.5) | 없음 | 완료 시 cmd 0x00F0 별도 통지 |

출력 모드 값은 `0x00000004`(engineering), `0x00000064`(normal)입니다.

### 4.4 파라미터 ID

| ID | 이름 | 범위 / 단위 |
|---|---|---|
| 0x0001 | 최대 거리 | 7~100 (0.1 m 단위, 즉 0.7~10 m) |
| 0x0004 | 대상 소멸 지연 | 0~65535 s |
| 0x0005 | 전원 간섭 상태 (읽기 전용) | 0 미실행 / 1 간섭 없음 / 2 간섭 있음 |
| 0x0010~0x001F | gate별 motion trigger threshold | 선형값 |
| 0x0030~0x003F | gate별 micro-motion threshold | 선형값 |

threshold는 Tool 화면의 dB 값 N과 UART 선형값 M 사이에 `M = 10^(N/10)` 관계가 있습니다. 예를 들어 70 dB는 10,000,000(`0x00989680`)입니다. 매뉴얼에 따르면 flash 저장은 **0x003F 파라미터 쓰기를 트리거로** 동작하므로, 값을 바꾸지 않더라도 0x003F를 읽어서 다시 써야 저장됩니다.

## 5. 방향(각도) 감지 가능 여부

LD2402는 **1T1R** 구조라 AoA(Angle of Arrival)를 계산할 수 없습니다. 좌/우 방향은 알 수 없고, 프로토콜에도 각도나 속도 필드가 없습니다. 거리의 시간 변화로 **접근/이탈(radial 방향)만 추정**할 수 있습니다. X/Y 좌표가 필요하면 1T2R 구조인 HLK-LD2450을 고려하십시오(최대 3명의 좌표와 속도를 제공).

## 6. 설치·운용 시 주의사항

- **전원 품질**: 전원 리플이 100 kHz 이내에서 뚜렷한 스펙트럼 피크가 없어야 합니다. 모듈은 부팅 후 10초간 전원 자가진단을 하며, 결과는 파라미터 0x0005로 읽을 수 있습니다. 100 µF + 0.1 µF 디커플링을 권장합니다.
- **부팅 직후**: 설정 명령이 바로 응답하지 않을 수 있으므로 재시도 로직이 필요합니다. 예제는 1초 간격으로 5회 재시도하고, 실패하면 ASCII 모드로 동작을 이어갑니다.
- **설치**: 천장 2.7~3 m 또는 벽 1.5~2 m 높이를 권장합니다. 센서가 흔들리면 오검출이 생기고, 안테나 back-lobe 때문에 센서 뒤쪽의 움직임도 감지될 수 있습니다. 커튼, 선풍기, 에어컨 바람에 흔들리는 식물이 대표적인 오검출 원인입니다.
- **하우징**: 24 GHz 투과성이 좋은 재질을 써야 하며, 금속은 사용할 수 없습니다.
- **여러 대 설치**: 24 GHz 센서끼리 빔을 마주 보게 두지 마십시오.
- **Engineering mode는 비영구 설정**으로 추정됩니다. 예제는 부팅할 때마다 다시 설정합니다.

## 7. 예제 설계에 반영한 사항

| 사양 | 예제 반영 |
|---|---|
| 165 ms 갱신 | 프레임당 최대 1회 IPC 전송 → 수신 측 shared memory overwrite race 없음 |
| 3가지 포맷 혼재 | byte 단위 state machine 하나로 ASCII / data / ACK 모두 처리 |
| 설정 모드 진입 필요 | enable → version → set mode → **항상** end config |
| 3.3 V IO | ESP32-S3는 직결, SR110은 레벨 시프터 필수 |
| 정지/운동 구분 | engineering mode에서만 가능 → 화면에 MOVE / STILL 표시 |
| 각도·속도 미제공 (1T1R) | 거리의 최소제곱 기울기로 radial speed 추정 → 접근 / 이탈 / 정지 판정 (`radar_trend.c`) |
